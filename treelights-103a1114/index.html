Before you start

  • A computer with Google Chrome or Microsoft Edge. Phones, Safari and Firefox can't do this.
  • A USB cable that carries data (some cables only charge).
  • Plug the small controller board of the tree into the computer.

Choose what to do

Update my tree Most people

Installs the newest firmware and keeps your light map, effects, timer and Wi-Fi settings.

When asked “Erase device”, leave the box unticked and press Next.

This browser can't talk to USB devices. Open this page in Google Chrome or Microsoft Edge on a computer. This page must be opened over https.

Fresh install

For a brand-new controller, or when the tree doesn't start any more. Erases everything on the board first.

Afterwards you calibrate the tree again and re-enter your home Wi-Fi.

This browser can't talk to USB devices. Open this page in Google Chrome or Microsoft Edge on a computer. This page must be opened over https.

How it goes

  1. Click the button. A window lists the USB ports: pick the one that appeared when you plugged the board in (often “CP2102” or “USB-SERIAL CH340”) and press Connect.
  2. Press Install and confirm. Keep the cable plugged in; it takes about a minute.
  3. When it says Installation complete, unplug the board and put it back in the tree. The lights come on by themselves.
  4. On your phone, join the Wi-Fi ChristmasTree (password TreeLights2026) and open http://tree.local, or your usual address if the tree is on your home Wi-Fi.

If something doesn't work

No port shows up in the list

Try another USB cable: many cables only charge. If it still doesn't appear, the computer needs the USB driver for the board's chip (CH340 or CP2102); search for the driver name, install it and plug the board in again.

It fails to connect, or stops halfway

Close any other program that might use the port (Arduino IDE, Cura…). Hold the FLASH button on the board, click the install button again, and let go once installing starts.

The tree doesn't remember its shape after updating

That happens if “Erase device” was ticked. Open the tree's page and run the calibration again (about two minutes).
